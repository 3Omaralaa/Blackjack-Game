# ♠️ Blackjack Game

A simple **Blackjack** card game built with **Python**.  
The game lets you play against the computer dealer, following the classic Blackjack rules.

## ✨ Features
- Deal random cards to player and dealer.
- Calculate scores automatically.
- Handle Blackjack (Ace = 11 or 1).
- Compare scores and announce winner.
- Replay option to start a new round.
